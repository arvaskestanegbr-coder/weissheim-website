# Features — Anleitung

Dieses Verzeichnis dokumentiert alle Features der WEISSHEIM-Website.

## Wie ein neues Feature dokumentiert wird

1. **Eintrag in `INDEX.md` hinzufügen** mit Status `planned`
2. **Status aktualisieren** wenn Arbeit beginnt → `in-progress`
3. **Nach Deploy** auf `done` setzen

## Status-Bedeutungen

| Status | Bedeutung |
|---|---|
| `planned` | Entschieden, noch nicht begonnen |
| `in-progress` | Aktuell in Entwicklung |
| `done` | Live auf weissheim.com |
| `cancelled` | Entschieden, nicht umzusetzen |

## Wann dieses Verzeichnis genutzt wird

- Bei neuen Feature-Ideen
- Zur Priorisierung
- Als Kontext für AI-Sessions (damit Claude weiß was bereits existiert)
